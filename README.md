
# HAKWallet – Ethereum Mini Wallet

## Tech Stack
- Flutter
- Flask (Python)
- PostgreSQL
- Ethereum Sepolia
- Alchemy

## Team
- Huy – Frontend
- Khanh – Backend
- Huyền Anh – Database

## How to run
### Backend
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py

### Frontend
cd frontend
flutter pub get
flutter run
